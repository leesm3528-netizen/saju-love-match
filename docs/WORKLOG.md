# 개발 기록

## 2026-10-12

하루 동안 아이디어 → 크롤링 → 궁합 로직 → 연출 → 배포까지 진행한 과정입니다.

### 1. 크롤링 준비
- Firecrawl API 키를 `.env`에 넣고(저장소 밖에 보관) 운세의신 평생사주 결과 페이지를 스크랩
- 결과 페이지는 **폼 POST 응답**이라 URL만으로는 빈 틀만 받아짐 → 입력 폼 구조를 분석해 직접 POST로 결과를 받는 방식으로 전환

### 2. 입력 화면과 궁합 로직
| 단계 | 내용 |
|---|---|
| 입력 폼 | 두 사람의 생년월일·나이(자동 계산)·키·몸무게·혈액형 |
| 혈액형 + 사주 궁합 | 연주·월주·일주 계산, 띠(육합·삼합·충·원진)·일간(천간합·상생·상극)·오행 보완 점수 |
| 체격 궁합 | 성별 없이 키 차이 크기와 BMI 차이(생활 리듬)로 점수화, 설명은 모두 긍정적으로 |
| MBTI 궁합 | 지표별 가감점 + 천생연분 조합. 처음엔 ESTJ×INFP가 76점으로 높게 나와 S/N 차이 감점을 키움 |
| ISFP × ENTJ | 요청에 따라 MBTI 100점, 종합 점수도 항상 1위(100점)가 되도록 예외 처리 |

### 3. 결과 연출
- 점수 카운트업 + 원형 게이지 + 항목 막대 애니메이션
- 내 사주에 **가장 부족한 오행**을 채워줄 이성 아바타 10종이 등장해 타이핑 효과로 멘트
- 하트가 날아오르는 효과, '동작 줄이기' 설정 존중

### 4. 운세의신 크롤러 (`crawler/`)
- robots.txt 전체 허용 확인, 요청 간격 2초, HTML 캐시
- 평생사주 120건(연속 60일 × 남녀) + 신통방통 궁합 12쌍 수집
- 사주명식 이미지 번호(a=천간, b=지지 寅=1 시작)를 파싱해 **내 사주 계산을 검증하는 데이터로 활용**
- 발견한 점: 태어난 시간을 "모름"으로 보내면 사이트가 **일주를 하루 전날로** 계산 → 기본값을 午시로 바꿈
- 결과: 73건 중 **72건 일치** (불일치 1건은 입춘 당일 밤 출생의 절기 근사 오차)
- 혈액형 궁합 페이지는 사이트 자체 버튼이 동작하지 않아 제외

### 5. 다른 사이트 조사 (포스텔러 · 놀부풍수 · 꿀점)
- 세 곳 모두 robots.txt는 허용하지만 결과가 **유료 / 로그인 필요 / 생성형 미리보기**
- 유료 콘텐츠는 수집하지 않기로 결정 → 결과 문구는 전부 직접 작성

### 6. 연애 리포트와 공유 링크
- 직접 쓴 문구로 리포트 구성: 연애 스타일(일간 오행 5종), 두 사람의 케미(오행 관계 5종), 행운의 데이트
- "인연이 들어오는 타이밍" 장은 커플 궁합 맥락에서 바람 이야기처럼 읽혀 **삭제**
- 결과 URL에 입력값을 담아 링크만으로 같은 결과를 재현

### 7. GitHub Pages 배포
- 공개 저장소 생성, 크롤링 데이터(`data/`)는 `.gitignore`로 제외, API 키가 없는지 확인 후 배포

### 8. 솔로 / 커플 분기
- 시작 화면에서 솔로/커플 선택 → `#solo`, `#couple`로 이동
- **솔로:** 어떤 사람을 만나는 사주인지 — 잘 맞는 띠·천간합 일간·MBTI 상위 3·혈액형·어울리는 키
- **커플:** 기존 궁합 점수 흐름
- 화면 로직을 `app.js`로 분리

### 9. 캐릭터 일러스트 교체
- 오픈 라이선스 아바타 세트(DiceBear Adventurer · Lorelei)를 시험했으나 "예쁜 애니메이션" 느낌이 아니라 제외
- SVG로 애니메이션풍 캐릭터를 직접 그림: 큰 눈과 하이라이트, 그라데이션 머리, 타입별 헤어스타일(양갈래·땋은 머리·히메컷 등)과 소품

### 10. 솔로 인연 매력 지수
- 솔로 결과에도 점수 애니메이션을 넣기 위해 오행 분포·도화로 매력·다정함·안정감·오행 균형 계산
- 처음 기준으로는 81%가 한 등급에 몰려, 10년치 생일 분포를 보고 등급 기준을 다시 정함 (12% / 40% / 39% / 9%)
