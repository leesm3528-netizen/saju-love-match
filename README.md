# 연애 사주 (saju-love-match)

생년월일·키·몸무게·혈액형·MBTI로 연애 사주를 보는 **연습용** 웹 서비스입니다.
처음에 **솔로 / 커플**을 고르면 각각에 맞는 화면으로 이동합니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

**사이트:** https://leesm3528-netizen.github.io/saju-love-match/

## 화면 흐름

```
시작 화면 ─┬─ 솔로예요  (#solo)   → 나의 정보 + 만나고 싶은 상대 성별 → 인연 매력 지수 → 캐릭터 등장 → 잘 맞는 사람 · 리포트
           └─ 커플이에요 (#couple) → 두 사람 정보                     → 궁합 점수     → 캐릭터 등장 → 항목별 궁합 · 리포트
```

### 입력 항목
성별 · 생년월일(양력) · 나이(생년월일로 자동 계산) · 키 · 몸무게 · 혈액형 · MBTI

### 솔로 결과
1. **인연 매력 지수** — 점수 카운트업 + 원형 게이지 + 항목 막대 애니메이션
2. **내 사주가 끌어당기는 인연** — 상대 성별의 캐릭터가 등장해 멘트 3개(인사 → 어떤 인연인지 → 마무리)
3. **나와 잘 맞는 사람** — 끌리는 기운, 잘 맞는 띠, 운명적 끌림(천간합 일간), MBTI 상위 3, 혈액형, 어울리는 키
4. **연애 리포트** — 나의 연애 스타일 / 내가 만나게 될 사람 / 행운의 데이트

### 커플 결과
1. **종합 궁합 점수** — 점수 카운트업 + 원형 게이지 + 항목 막대 애니메이션
2. **캐릭터 등장** — 점수 구간(80+ / 60+ / 그 외)에 따라 다른 멘트
3. **연애 리포트** — 나의 연애 스타일 / 두 사람의 케미 / 행운의 데이트
4. **항목별 궁합** — 사주 · MBTI · 혈액형 · 체격 상세 풀이
5. **두 사람의 정보** — 입력값과 띠·연주·월주·일주

### 공통
- **공유 링크** — 결과를 보면 주소창이 공유 가능한 URL로 바뀌고 "링크 복사" 버튼이 생김. 링크를 열면 같은 결과가 바로 나옴
- **캐릭터 일러스트** — 외부 이미지 없이 SVG로 직접 그린 애니메이션풍 캐릭터 10종 (등장·둥실·눈 깜빡임·말할 때 입 움직임)
- **동작 줄이기** — 기기에서 '동작 줄이기'를 켠 사용자에게는 애니메이션 없이 결과를 바로 표시

## 점수 계산

### 커플: 종합 궁합 점수
`사주 45% + MBTI 25% + 혈액형 15% + 체격 15%`
(예외: MBTI가 ISFP × ENTJ 조합이면 종합 100점. 다른 조합의 이론상 최대는 97점)

| 항목 | 계산 방법 |
|---|---|
| **사주** | 50점에서 시작해 가감 (0~100)<br>· 띠: 육합 +20 / 삼합 +15 / 같은 띠 +5 / 원진 −10 / 충 −15<br>· 일간: 천간합 +20 / 상생 +10 / 같은 오행 +5 / 상극 −10<br>· 오행 보완: 한쪽에 없는 오행을 상대가 2개 이상 가지면 +5 (최대 +15) |
| **MBTI** | 60점에서 시작. S/N 같으면 +15·다르면 −15, E/I 0·+10, T/F +5·+8, J/P +4·+3<br>흔히 알려진 천생연분 17조합은 최소 95점, ISFP × ENTJ는 100점 |
| **혈액형** | 10가지 조합별 점수표 (예: A×O 90, B×AB 85, A×B 50) |
| **체격** | 키 차이 60% + BMI 차이 40%<br>· 키 차이: 8~15cm 100점, 3~8cm 90점, 15~20cm 85점 …<br>· BMI 차이: 2 이하 95점, 4 이하 85점 … (생활 리듬이 비슷한지로 해석) |

### 솔로: 인연 매력 지수
연·월·일주 6글자의 오행 분포와 도화(子·午·卯·酉)로 4개 항목을 계산해 평균 (각 40~100점)

| 항목 | 기준 |
|---|---|
| 매력 | 도화 개수 + 화(火) |
| 다정함 | 목(木) + 수(水) |
| 안정감 | 토(土) + 금(金) |
| 오행 균형 | 다섯 오행이 고루 있을수록 높음 |

등급은 모두 긍정적인 문구이며, 10년치 생일 분포에 맞춰 기준을 정했습니다.
인연이 줄을 서는 사주(81+, 약 12%) · 매력이 넘치는 사주(76+, 40%) · 천천히 빛나는 사주(71+, 39%) · 숨은 매력이 많은 사주(9%)

### 사주 계산
- **연주:** 입춘(2/4) 기준으로 해가 바뀜
- **월주:** 12절기의 평균 날짜로 월지를 정하고, 연간으로 월간을 계산 (갑기년 → 병인월)
- **일주:** 2000-01-01 = 戊午일 기준으로 60갑자 순환
- **검증:** 운세의신 사주명식 73건과 비교해 **72건 일치**. 불일치 1건(2000-02-04)은 그해 입춘이 2월 4일 밤이라 생긴 절기 근사 오차

### 캐릭터 선택
내 사주에서 **가장 부족한 오행**을 채워주는 타입이 등장합니다(동률이면 일간을 생해주는 오행). 캐릭터 성별은 상대 성별을 따릅니다.

| 오행 | 남자 캐릭터 | 여자 캐릭터 |
|---|---|---|
| 木 | 다정한 문학 소년 (부드러운 앞머리·나뭇잎) | 싱그러운 청순형 (긴 생머리·꽃핀) |
| 火 | 열정적인 리더형 (뾰족 머리) | 밝은 에너지 걸 (양갈래·리본) |
| 土 | 듬직한 곰돌이형 (곱슬) | 따뜻한 힐링형 (옆으로 땋은 머리) |
| 金 | 시크한 차도남 (넘긴 앞머리·귀걸이) | 도도한 시크형 (일자 앞머리·귀걸이) |
| 水 | 지적인 감성남 (가르마·안경) | 신비로운 지성형 (단발·안경) |

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조와 스타일 (시작 / 입력 / 결과) |
| `app.js` | 화면 흐름 — 솔로/커플 분기, 결과 렌더링, 애니메이션, 공유 링크 |
| `compat.js` | 궁합 점수 계산 — 사주(연·월·일주), MBTI, 혈액형, 체격 |
| `report.js` | 연애 리포트 문구, 솔로용 잘 맞는 사람 계산, 인연 매력 지수 |
| `avatar.js` | 캐릭터 10종의 설정과 멘트, 캐릭터 선택 로직 |
| `anime-avatar.js` | 캐릭터 일러스트 SVG 그리기 |
| `crawler/` | 운세의신 크롤러와 사주명식 검증 스크립트 ([crawler/README.md](crawler/README.md)) |
| `docs/WORKLOG.md` | 개발 과정 기록 |

## 로컬 실행

`index.html`을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

```bash
# 사주 계산 검증 (크롤링 데이터가 있을 때)
node crawler/validate_pillars.js
```

## 배포

GitHub Pages(`main` 브랜치 루트)로 배포됩니다. `main`에 push하면 1~2분 뒤 사이트에 반영됩니다.

## 한계와 주의

- 태어난 시간을 받지 않아 **시주는 계산하지 않습니다.**
- 절기를 평균 날짜로 근사하므로 절기 당일 전후 출생자는 월주·연주가 하루 차이로 틀릴 수 있습니다.
- 양력 생일만 지원합니다.
- 공유 링크에는 생년월일·키·몸무게가 그대로 들어갑니다.
- 모든 점수와 풀이는 **재미를 위한 것**입니다.
- 크롤링한 데이터(`data/`)는 다른 사이트의 저작물이라 저장소에 포함하지 않습니다.
