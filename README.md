# 💕 연애 사주 (saju-love-match)

생년월일·키·몸무게·혈액형·MBTI로 연애 사주를 보는 연습용 웹 서비스입니다.
처음에 **솔로 / 커플**을 고르면 각각에 맞는 화면으로 이동합니다.
빌드 없이 정적 파일만으로 동작합니다.

## 기능

### 솔로 (`#solo`)
- 내 정보만 입력 → **인연 매력 지수**(매력·다정함·안정감·오행 균형) 점수 애니메이션 → **내 사주가 끌어당기는 인연** 캐릭터가 등장해 멘트
- 나와 잘 맞는 사람: 끌리는 기운, 띠(육합·삼합), 천간합 일간, MBTI 상위 3, 혈액형, 어울리는 키
- 연애 리포트: 나의 연애 스타일, 내가 만나게 될 사람, 행운의 데이트

### 커플 (`#couple`)
- **종합 궁합 점수** — 사주 45% · MBTI 25% · 혈액형 15% · 체격 15%
- **사주 궁합** — 생년월일로 연주·월주·일주를 계산해 띠 궁합(육합·삼합·충·원진), 일간 궁합(천간합·상생·상극), 오행 보완을 점수화
- **결과 연출** — 점수 카운트업 애니메이션, 내 사주에 부족한 오행을 채워줄 캐릭터(남녀 각 5종)가 등장해 멘트
- **연애 리포트** — 연애 스타일, 두 사람의 케미, 행운의 데이트

### 공통
- **공유 링크** — 결과 URL(`?mode=...&me=...`)을 열면 같은 결과가 바로 나옴
- **캐릭터 일러스트** — 외부 이미지 없이 SVG로 직접 그린 애니메이션풍 캐릭터 10종

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조와 스타일 |
| `app.js` | 화면 흐름 (솔로/커플 분기, 결과 렌더링, 공유 링크) |
| `compat.js` | 궁합 점수 계산 (사주·MBTI·혈액형·체격) |
| `anime-avatar.js` | 캐릭터 일러스트 SVG 그리기 |
| `avatar.js` | 캐릭터 10종의 설정과 멘트 |
| `report.js` | 연애 리포트 문구, 솔로용 잘 맞는 사람 계산 |
| `crawler/` | 사주명식 검증용 크롤러 (연습용, 수집 데이터는 저장소에 포함하지 않음) |

## 로컬 실행

`index.html`을 브라우저로 열면 됩니다.

## 한계

- 태어난 시간을 받지 않아 시주는 계산하지 않습니다.
- 절기는 평균 날짜로 근사합니다. 절기 당일 전후 출생자는 월주·연주가 하루 차이로 틀릴 수 있습니다.
- 모든 풀이와 점수 기준은 재미를 위한 것입니다.
